# Geant4 X-ray Imaging Simulation

GEANT4 simulation developed for my BSc Physics thesis at the University of Debrecen.

## Goal
Investigate multi-source X-ray configurations to improve depth perception in imaging systems.

## Features
- Custom detector geometry
- Multiple angled radiation sources
- Visualization using Geant4 OpenGL
- Event generation macros

## Requirements
- Geant4 11.x
- CMake
- ROOT (optional)

## Build

mkdir build
cd build
cmake ..
make

## Run

./simulation run.mac
